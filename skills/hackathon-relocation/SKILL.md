# Перенос хакатона: сетка слотов и сводный бюллетень

## Когда применять

Навык нужен для задачи целиком: бронь площадки, сетка слотов для всех команд, рассылка и итоговый бюллетень. Для вопроса о текущем состоянии хватает `get_status`, навык для него не нужен.

## Порядок расстановки слотов

Расстановка идёт после брони и только на забронированной площадке. Данные бери из `list_venues`, `get_roster` и `read_inbox`.

1. Раздели команды по трекам. У каждого трека свой зал и свой ментор: зал, в поле `tracks` которого есть трек, и ментор с тем же значением `track`.
2. Для каждого трека составь два списка слотов по возрастанию времени.
   - Слоты менторских сессий: те, что есть и в `available_slots` ментора, и в `available_slots` зала.
   - Слоты питчей: остальные слоты зала.
3. Сначала размести команды с пожеланиями из входящих писем. Пожелание учитывается, когда его прислал капитан этой команды и названный слот свободен и входит в списки из шага 2. Иначе пожелание пропускается, команда идёт в общую очередь.
4. Остальные команды трека расставь по возрастанию `id`: каждой первый свободный слот менторской сессии и первый свободный слот питча.
5. Проверь сетку до отправки:
   - в одном зале каждый слот занят одной командой;
   - у одного ментора каждый слот занят одной командой;
   - слот менторской сессии и слот питча одной команды различаются;
   - у каждой команды есть оба слота.
6. Отправь всю сетку одним вызовом `assign_slots`. Если часть назначений отклонена, исправь только их по тексту отказа и отправь заново. Принятые назначения повторять не нужно.
7. Убедись через `get_status`, что список `pending.teams_without_slots` пуст.

## Рассылка

Отправь одним вызовом `send_notifications` по одному письму каждому капитану и каждому ментору. Площадку, зал и слоты сервер дописывает в письмо сам, время в тексте не указывай. Отклонённое письмо исправь по тексту отказа. Адресатам со статусом `already_sent` второе письмо не нужно.

## Сводный бюллетень

Итоговый ответ состоит только из бюллетеня по шаблону ниже. Заголовки в квадратных скобках пиши дословно. Данные бери из последнего ответа `get_status`, а не по памяти.

```text
[ПЛОЩАДКА]
<название площадки> (<id площадки>), бронь <booking_id>, <стоимость> KZT

[СЕТКА СЛОТОВ]
<id команды> <название команды>: зал <hall_id>, ментор <имя ментора>, менторская сессия <слот>, питч <слот>
(по одной строке на каждую команду, по возрастанию id)
Конфликтов расписания: 0

[СТАТУС РАССЫЛКИ]
Команды: <отправлено> из <всего>
Менторы: <отправлено> из <всего>
```

Строку `Конфликтов расписания: 0` пиши, когда `assign_slots` принял все назначения и в `pending.teams_without_slots` пусто. Если перенос не удался, вместо бюллетеня напиши, какой шаг не выполнен и какой отказ вернул инструмент.
